# openclaw-test3

## How to Run

1. Clone the repository:
   ```sh
   git clone https://github.com/bbbyk105/openclaw-test3.git
   cd openclaw-test3
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the server:
   ```sh
   node src/app.js
   ```

The server will run on `http://localhost:3000`.
